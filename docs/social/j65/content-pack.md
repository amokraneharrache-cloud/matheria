# J65 — 3 questions avant la Terminale spé maths

## Source et correction

Les trois questions proviennent de la banque validée du diagnostic SprintMaths,
sans reprendre exactement la sélection J61 :

- `q-124` : `(x² − 4)/(x − 2) = x + 2` pour `x ≠ 2`, par factorisation de `x² − 4` ;
- `q-197` : si `uₙ₊₁ = 0,5uₙ` et `u₀ = 16`, alors `u₄ = 16 × 0,5⁴ = 1` ;
- `q-244` : `(2 ; 3) · (−1 ; 4) = 2 × (−1) + 3 × 4 = 10`.
