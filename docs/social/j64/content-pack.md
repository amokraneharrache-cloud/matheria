# J64 — Intégrale vraie ou fausse

## Source et vérification

- Sujet officiel : Bac général 2026, spécialité mathématiques, Asie jour 1, exercice 2, affirmation 4.
- Énoncé : `v_n = ∫₀¹ e^(nx) dx`, puis affirmation `v_n = e^n / n`.
- Verdict : faux, car pour `n ≥ 1`, une primitive de `e^(nx)` est `e^(nx) / n`, donc `v_n = (e^n - 1) / n`.
- PDF officiel : https://www.education.gouv.fr/sites/default/files/document/baccalaureat-general-2026-mathematiques-jour-1-517442.pdf
